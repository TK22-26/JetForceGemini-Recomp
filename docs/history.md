# Historical documents

Current instructions start at the [documentation index](README.md). Superseded
planning estimates, publication discussions, experiment journals, and one-off
research scripts have been removed from the working tree.

The [source snapshot before this cleanup](https://github.com/TK22-26/JetForceGemini-Recomp/tree/2c55b0f082395e2be4407958637dbb4effb3c43d) retains the original files.
In a clone, use `git log --all -- path/to/file` to find changes and
`git show <commit>:path/to/file` to read a historical version.

Historical results apply to their recorded source, tools, inputs, and execution
profiles. They do not certify the current build or reopen a stopped investigation.
Active [acceptance contracts](planning/README.md), signed records, required
attribution, and operational guard instructions remain in the working tree.
