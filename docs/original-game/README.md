# Original game: N64 bugs and regional differences

This catalog records what the original game does independently of the recompilation.
A bug belongs in the confirmed list only after observation on a physical N64. Original-ROM emulator
results are useful evidence, but must name the emulator and remain distinct from hardware confirmation.
A difference between ROM regions is not automatically a bug.

- [Native bug catalog](bugs.md): hardware-confirmed and owner-reported observations, reproduction, provenance, cause and the recomp's decision.
- [Regional differences](regional-differences.md): NTSC/PAL/JP observations and unanswered comparisons.
- [Investigation records](../development/issues/README.md): detailed attempts and fixes, including recomp-only defects.

For each new entry record region/revision or hash when known, console/video path, observer/date,
reproduction and expected/actual behavior, evidence origin, cause (or unknown), and a decision:
preserve, fix, optional correction, or undecided. Never infer a hardware test from an emulator replay.
Correct earlier mistaken observations explicitly. Link the issue and real commit/release when available;
keep ROMs, captures containing game data and personal saves private.
