# 0.5.0-preview.1: unified Windows frontend

Release candidate. Publication and physical multiplayer qualification are separate.

## Changes

- One native window for home, setup and gameplay, with a menu available during play.
- Four independent N64 controller ports. Automatic assignment discovers separate
  XInput devices; each player can override assignment, disable a port, or use the
  single shared keyboard. Individual mappings, deadzones and inversion apply live.
- Controllers and Audio menus capture physical gameplay input. Held controls must
  be released before they reach the game again. Volume and mute apply live.
- F11 borderless fullscreen, Esc settings, remembered window placement and DPI
  scaling. Fullscreen uses the whole window and preserves the game aspect ratio.
- Stop returns to home. Startup can be cancelled or closed; a crashed game session
  returns to home with support reports available.
- The setup/settings helper is embedded in the launcher. Game code and assets
  continue to be built locally from the user's supported ROM.

## Updating

An older game build does not have the window-hosting protocol. Use **Set up and
build** to build the source revision pinned in the new launcher. Existing default
profile saves are retained. Testing mods still use their separate save profile.

Automatic controller assignments remain reserved across disconnects during the
session. XInput can renumber hardware across reconnects or restarts. For explicit
device preview or binding capture, select a numbered controller in its player tab.

## Validation

- Fresh Windows native game build, native frontend build, and managed helper build.
- 471 launcher checks, 12 setup fixture checks, and three focused C++ controller/SI
  test executables passed.
- Isolated UI tests passed repeated start/stop, startup cancellation/close,
  windowed/fullscreen transitions, F11 through the game window, settings capture,
  mute persistence, and recovery from a deliberately terminated test session.
- Four-port SI packet delivery, independent profile persistence, duplicate-device
  prevention, disconnect isolation, automatic assignment and all-player release
  gating have automated coverage.

Two/four physical-controller multiplayer, fresh-PC installation/UAC/reboot, and
long play sessions through cutscenes still need qualification. Devices that do
not expose XInput require a compatible driver or adapter. These checks do not
establish complete original-console parity.
