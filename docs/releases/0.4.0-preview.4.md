# JFG Launcher 0.4.0-preview.4

Graphics completion now follows the original game's yield request during
the Vela unlock sequence. Audio continues playing while buffered samples
remain, removing the avoidable pause observed in that scene. Recycled
renderer memory is refreshed for CPU textures, fixing the recorded opaque
water-splash rectangle.

## Changes

- Correct pending graphics completion timing during audio scheduling.
- Keep nonempty audio queues playing while retaining startup buffering and
  recovery after a genuine underrun.
- Restore particle transparency after framebuffer memory is reused.
- Allow longer input recordings and preserve bounded replay parsing.
- Add an opt-in Juno double-run-speed mod setting. Normal gameplay is unchanged.

Existing volume/mute controls, crash reports, controller mappings, shadows,
live map/inventory and experimental navigation remain available.

## Playtest progress

Maintainer-reported progress: Juno reached Mizar's Palace after Tawfret;
Vela was tested up to Cerulean; Lupus progress has not yet been reported.
These sessions used health/enemy-clearing mods. They demonstrate traversal
coverage, not complete unmodified campaign or original-console accuracy.

## Validation and remaining checks

- Eight focused native renderer, scheduler, audio/graphics bridge, replay,
  playback-buffer and mod tests passed.
- Two 30,642-VI particle replays completed normally. The matching comparison
  retained identical final CPU memory while restoring splash transparency.
- The current native runtime was rebuilt with both timing and particle fixes.
- The earlier real-time Vela sequence replay recorded no audio underruns or
  interior audio pauses; audible confirmation still needs a playtest.
- The maintainer confirms all previously reported broken particle effects now
  render correctly: splash, dust, pickup sparkles, ship exhaust and Tawfret rain.
  Juno water effects remain untested.
- One prior run failed in DirectX shader compilation near a Windows desktop
  compositor failure. Monitored reruns succeeded; its cause remains unconfirmed.
- Windows 10 setup limitations and experimental navigation restrictions remain
  as described in [known issues](../known-issues.md).

## Install

Use your supported US big-endian ROM. Select **Set up and build** again to
build this launcher's pinned source revision, then launch with your existing
save profile. The package contains the launcher, setup guides and license.
It does not contain a ROM, game assets or a generated game executable.
