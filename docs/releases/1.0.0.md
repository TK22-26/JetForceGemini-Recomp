# Jet Force Gemini Recomp v1.0.0

The first stable Windows x64 release combines full campaign progression with
a native launcher, game rendering and audio, and optional PC conveniences.
Supply your own supported North American ROM; game content is built locally.

## Download and upgrade

Download `JFG-Launcher-1.0.0-windows-x64.zip` from the
[release](https://github.com/TK22-26/JetForceGemini-Recomp/releases/tag/v1.0.0).
Extract the complete ZIP and run `JFG-Launcher.exe`. Keep the included license
files. Existing users should run **Set up and build** to rebuild the game from
this launcher's pinned source revision; existing saves remain in the profile.
See [getting started](../getting-started.md).

## Included

- Unified launcher with setup, home, in-game menus, fullscreen, audio settings
  and support-report tools.
- Live map and live inventory in custom companion windows. Inventory artwork
  is extracted locally from your ROM and is not distributed in the package.
- Configurable keyboard/XInput controls and controller-port assignment.
  Experimental mouse look and dual-stick controls are available as opt-in
  single-player features with device-specific settings.
- Opening asteroid texture and lens-flare occlusion corrections, plus reduced
  renderer memory overhead that removes reproduced intro audio interruptions.
- Original guest OS/device timing and the integrated Quarry audio synchronization
  and performance fixes, with independent window handling.
- Particle-texture corrections, player-shadow processing, and verified
  saving/loading.
- Optional gameplay and navigation mods, with documented traversal limits.

## Verification and limits

The maintainer completed the campaign using optional infinite-health and
enemy auto-kill testing mods and a save with all Tribals unlocked. This confirms
campaign progression; broader unassisted play and original-console accuracy
remain under validation. The owner accepted the corrected opening cinematic.

A fresh build from the supported ROM passed two complete opening replays and
one Quarry cutscene/gameplay replay at a verified 1920x1080 viewport, with zero
audio underruns/overruns and no detected Windows output gaps lasting at least
6 ms. All 81 ROM-free C++ tests, three renderer regressions and automated
single-player controller checks pass. This does not establish perfect frame
pacing on every PC. See [renderer findings](../planning/phase7-renderer-integration.md),
[Quarry findings](../planning/quarry-audio-sync-findings.md) and the
[combined validation](../../evidence/unified-original-timing-validation.json).

Windows 10 prerequisite installation still has reported limitations. Original
multiplayer and optional content need broader testing; experimental PC controls
are not qualified for split-screen. Review [known issues](../known-issues.md)
and [PC controls status](../planning/pc-controls-status.md).
