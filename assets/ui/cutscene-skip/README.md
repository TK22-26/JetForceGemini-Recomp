Original artwork generated with OpenAI image generation on 2026-10-19 at the
owner's request. The source PNG is preserved unchanged. The compiled payload
is 32x32 RGBA16; the ring, label and confirmation animation are rendered by the
game, not baked into this image. No SVG or host overlay.

compiled to a 64x24 RGBA16 native texture. Its license is included here.
