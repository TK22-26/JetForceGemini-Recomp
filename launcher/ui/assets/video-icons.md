# Video settings tab icons

The adjacent video-icon-screen.svg, video-icon-gauge.svg,
video-icon-layers.svg and video-icon-spark.svg are project-authored line
drawings for the owner-requested video settings tabs. They contain no game
art. video-icons.tga is their local raster atlas used by the RmlUi backend.
The vector sources remain editable. These project UI assets use the project
license; they are not imported from the game's ROM.

The release source checker allows only the reviewed atlas digest recorded
in scripts/reviewed_hygiene_bodies.json. Changing its bytes requires review.
