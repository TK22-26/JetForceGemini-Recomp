# Live map settings icons

Local line drawings for the owner's Live map settings HTML reference (2026-10-21): map, robot, wrench, warning, weapons and an open padlock with sparkle for Floyd. The atlas contains no game art or extracted assets. The adjacent generate_mods_icons.py records the editable path points; each cell is 64 pixels for a 16dp icon at 4x resolution. Two tab rows carry inactive and selected colors. The native launcher embeds the atlas and never downloads fonts or artwork.
